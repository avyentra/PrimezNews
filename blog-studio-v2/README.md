# Blog Studio 2.0 — standalone local MVP
Windows: install Python 3.10+ and Ollama (https://ollama.com/). Open PowerShell in this folder, run `ollama pull qwen2.5:7b` and `ollama pull llama3.1:8b`, then `python app.py`. Open http://127.0.0.1:8765. Ollama must be running. No paid API is used. Models require several GB of disk and adequate RAM; CPU inference may be slow. No dependency installation required.
Enter topic and 2–5 distinct relevant official HTTPS source pages. The app retrieves the actual text, builds a research brief, writes a US-English Markdown article, runs deterministic checks and a separate reviewer model, retries at most three times, and saves the report to drafts/. No publishing endpoint. Export JSON for manual review. Source redirects and non-allowlisted hosts are rejected; use final official HTML URLs. Models may omit claims, misinterpret evidence or inflate scores; a 90 score is not certification. Local duplicate comparison is not internet-wide plagiarism detection. No measured CPC, automatic discovery, live search, Gemini, Supabase integration or scheduled operation in this MVP. Source selection is manual. Never expose this development server publicly. Human expert review is required for high-stakes topics. Test with `python -m unittest test_app`.
